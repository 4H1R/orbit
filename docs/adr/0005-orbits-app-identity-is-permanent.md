# Orbit's app identity is permanent

Orbit is sideloaded, so Android allows an update only when the new APK has the same applicationId and the same signing key as the installed one. If either changes, the only way forward is to uninstall, which deletes every Person on the phone unless a recent Backup exists. The applicationId is therefore fixed as **`dev.alializadeh.orbit`**, and debug builds use `dev.alializadeh.orbit.debug` so they install next to the real app without touching its data. The release keystore is generated once, never committed, and kept in two places: the password manager and an offline copy. A namespace owned by an employer (`studio.oversight.*`) was rejected because Orbit is a personal app. A bare `app.orbit`-style id was rejected because it could collide with a real app on the phone.
